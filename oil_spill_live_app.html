Live Analysis

Oil Spill Attribution — Run It Yourself

1

Connect. This page doesn't do the actual computing itself — it sends your request to a real Python program running in a Colab notebook, reachable at whatever web address you paste in here. If that notebook isn't running, nothing else on this page will work.

2

Choose an image. Picking one of the 14 listed images instantly shows it with a segmentation heatmap already applied — a red overlay marking where the model is confident oil is present. These 14 heatmaps are precomputed ahead of time, not calculated when you click, which is why this loads immediately rather than making you wait. Validated against real ground-truth masks across 5 spills: 48% precision, 64% recall — meaning it's better tuned to not miss real oil than to draw a pixel-exact boundary, which is the right trade-off for pointing responders toward roughly the right area quickly. Clicking a point on it tells the system exactly which 256×256 pixel patch to examine for the detailed suspicion analysis below.

3

Tune the settings. The threshold slider controls how confident the model must be before calling something "oil" — lower it to catch more possible spills at the risk of more false alarms, raise it to be stricter. The three weight sliders control how much distance, direction of travel, and AIS signal gaps each count toward a ship's suspicion score.

4

Analyze. The patch you picked gets checked for oil, its real-world location gets calculated, a set of nearby ships gets generated and scored, and the results appear ranked by suspicion — all in that one request.

If you upload your own image instead of picking one from the list: oil detection will still work normally. But the real-world location shown afterward will only be accurate if your file has "georeferencing" embedded in it — hidden location data that scientific satellite image formats (like the Sentinel-1 GeoTIFFs this system was built on) carry, but ordinary photos and screenshots don't. Without it, the location shown falls back to an approximate placeholder point in the Gulf of Mexico, and the page will say so plainly rather than pretending it's exact.
